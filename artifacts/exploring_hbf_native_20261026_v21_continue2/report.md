# 原生后端论文对照实验

更新：2026-10-27T03:31:44.181127+00:00；状态：完成。
配置 30 组，成功 30，全候选拒绝 0，失败 0。

每配置固定 8 GPU；部署按论文式搜索：旁路模型筛选布局并给出批量区间，原生在旁路排名前2且原生可组合的布局上各测最多6个有效批量点、最多10次尝试，把TPOT上界线性插值到100ms，再在最佳布局的插值批量上做一次原生验收；最终数字只取原生候选，旁路数值只用于放置批量点。够不到100ms的布局停在已测最大点并标注受限，不外推；验收未通过时退回已测通过点。DP 副本是互相独立的拷贝，只仿真一个副本，集群吞吐为单GPU吞吐乘GPU总数。每配置选择通过 100ms 请求均值TPOT约束的最高预算接受的预测单GPU吞吐，不表示全局最优部署或最大批量。
完整原生批次样本与预测窗口分开保存；10%为明示条件模型预算，不是未执行全窗口的实测保证。预测尾段没有物理轨迹，预算拒绝时指标为空，不回退详细后缀。
预测吞吐使用相同测量窗口及可见Token定义，TPOT使用窗口内完整新请求的首末Token预测区间；预测完成不计为物理完成。
TTFT = Prefill通路 + 入口TTFT。Prefill副本为HBM4、与Decode副本相同的TP/PP/EP布局，请求到达即单独计算完整的前P-1个提示Token（不排队、不额外限制分块，保留模型强制分块），到最后一块的最后一层完成为止（此时开始导出KV）；入口TTFT从该请求实付KV导入开始到首个Token，Decode侧计算最后一个提示Token并给出首Token。单段Prefill使用分层采样；多段层采样仍是默认停用的独立误差试验，未通过试验时不以完整原生慢跑替代。已接受通路区间与入口TTFT区间相加，并检查同一独立预算。
DRAM/NAND/SRAM与PD真实账本只覆盖采样前缀；全窗口物理流量未知。预测尾段不生成虚构的流量、利用率或物理状态。
