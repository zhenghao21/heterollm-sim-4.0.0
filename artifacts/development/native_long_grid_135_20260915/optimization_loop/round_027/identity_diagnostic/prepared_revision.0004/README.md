## 预算计算与预检

262份冻结prediction引用长度合计1,846,642,198字节。每次终态门禁还必须全文检查campaign控制/冻结文件以及barrier，前、中、后三次完整检查必然超过旧2GiB上限。新预算由源码中的纯整数公式计算：

- 三次 `campaign refs + barrier + 262 prediction refs`，长度来自已冻结引用，准备时检查实际文件长度。
- 三次源码、Python/OpenSSL/CNG运行库、协议、准备清单及历史失败证据的完整核验。
- 一次预算预检清单读取。
- 五份新分块日志：由固定块数和最长JSON行字节数推导上限。
- 五份pass finish各最多1MiB，五份内存控制回执各最多64KiB；读取前逐文件执行这些上限。

为解决协议/清单包含自身预算造成的循环，只对协议长度预留1MiB、清单64KiB；其余已存在文件使用实际冻结长度。总和仅向上取整到1MiB。`metadata_budget_plan`记录所有项、次数、必需上界和声明上限，运行前必须重新推导一致；尺寸变化或公式不一致会在读取模型内容前拒收。

长度检查只负责预算规划，不代替内容身份。前、中、后三次终态门禁仍完整读取并SHA核验262份预测；程序和运行库仍完整核验。模型内容不能混入辅助读取清单。

新批次模型逻辑读取上限仍为五遍：74,325,580,640字节。此前一遍单列为14,865,116,128字节，两批累计上限89,190,696,768字节。OS缓存、页入和物理磁盘字节不由该逻辑读取上限表示。
