时间线的前提是 generic_nand 读服务：A 和 B 是映射到同一 plane 的两个不同未命中页，请求已准入，没有写暂存覆盖，两个读槽初始为空。灰色代表 A，棕橙代表 B。每页先阵列读取，再内部填槽，最后 host 输出，这是实线连接的同页依赖。虚线强调另一条约束：A 的内部搬运结束、介质暂存释放后，才允许同 plane 的 B 开始阵列读。因此，读 B 不能与填 A 重叠，但可以与输出 A 重叠。B 用另一个槽，所以填 B 也可与输出 A 重叠。

同一内部通道和同一 host 读出口都不能同时服务两次传输，输出 B 必须等自身填充结束并等 host 空闲。图中的下方括线表示出口 A/B 不能重叠。若下一页需要覆盖槽 A，新的内部填槽还必须等槽 A 的最晚旧读者结束；阵列读本身可以先结束，数据在介质暂存中等候，这段等待也会阻止同 plane 再读下一页。host 输出结束不会自动清空缓存页，只解除覆盖约束，所以该页以后仍可能命中。图的长短没有数值比例，也不保证理想流水。源码为 src/heterollm_sim/nand_core.py:1817–1819、1901–1956、647–665，以及 memory_transfer.py:263–335。
