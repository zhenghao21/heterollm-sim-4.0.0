# HBM 仿真执行速度优化

本轮优化减少仿真器自身的计算和状态处理开销。模型、硬件参数、每条内存命令的执行规则和预测精度保持原样。性能测量和等价检查见 [本轮结果](../artifacts/hbm_execution_performance_20261015/report.md)。

## 慢在哪里

大块访存主要消耗在逐 burst 的命令计算。当前实验每个 burst 为 32 字节，128 MiB 访问需要处理 4,194,304 个 burst；70B 模型仅一次完整 BF16 权重读取就约为 131.414 GiB。因此即使只生成几个 token，命令数也很大。512 GiB 工作点的一次 128 MiB 读诊断中，数值执行核约占总时间的 97%，已经启用 Numba 编译执行，并非退回 Python 逐条解释。

小请求和完整推理还会反复整理、保存控制器状态。该工作点有 16,384 个 bank 和 256 个 pseudo-channel。原来每次提交都会重建资源名称，并将所有已有 bank 写回；运行时保存状态还会重复调用通用深复制。Small 完整推理的诊断共发生 113 次数值执行入口调用、152 次运行时状态保存，时间较多地花在这些外围操作上。

## 已实施的修改

1. 数值核心在维护检查完成、当前行仍命中时，复用刚计算出的列命令时间。每个请求固定的恢复时间只计算一次。仍逐条处理所有 burst，保留 float64、时钟对齐顺序和 `fastmath=False`。
2. 按几何和资源前缀缓存不可变的资源名称及索引。每次请求仍读取当前控制器、资源别名和时间线状态；缓存不保存可变控制器状态。
3. 使用数组精确比较找出变化的 bank/channel，仅写回这些项目。浮点比较包含正负零差异；刷新影响到的其他 bank 同样写回。所有已出现 pseudo-channel 的嵌套历史仍按原方式重建，保留扩展字段引用行为。
4. 对普通字典、列表和标量历史使用专用复制路径；保留循环、共享引用和自定义对象的深复制协议及 memo 替换行为。请求失败和批量前缀的恢复逻辑保持原样。

没有调整请求顺序、批量边界、刷新次数、地址映射、模型尺寸或时序参数，也没有使用抽样、跳过命令、低精度计算或分析带宽公式替代命令执行。

## 验证方法

完整推理基准使用 Small、输入 128 token、批量 1、输出 4 token，覆盖 reference/ramulator2 两套参数与 A 全 HBM/B 的 KV 使用 HBF 两种放置，每组重复三次。优化前后分别在独立进程加载，均先预热编译器，比较完整返回数据，仅排除仿真器实际运行耗时字段。预测 TTFT、TPOT、吞吐、命令计数、资源统计和执行检查均参与比较。

数值核心另有 128 MiB 连续读写、同 bank 换行和多配置续接对照，逐请求结果及全部 14 个数组均作无容差比较。回归覆盖命令时序、刷新、tFAW、非二进制时钟、调度、异常恢复、扩展引用及运行时保存/恢复。

上述第一轮测量期间，原来的八个大模型实验仍在运行，故耗时是本机有其他负载时的测量。局部数值核和 Small 完整流程的加速倍数分别报告；没有将它们直接当作 70B/235B 完整仿真的加速倍数。

随后按用户要求停止旧八进程，仅重跑 70B 的四个对照点并加入进度监控，见 [70B 运行记录](../artifacts/hbm_70b_optimized_20261015/README.md)。进一步尝试的 deadline 增量维护、历史时钟缓存、时钟除法合并及 ACT 时间复用，未能同时满足完整语义和真实大请求的性能要求，均未保留。当前正式核心保留上文四项第一轮优化。

70B 四点现已全部完成，单点实际耗时约 208–221 分钟，最终数值核心占实际耗时约 89.3%–89.7%。完整预测、执行检查与结果边界见 [70B 最终报告](../artifacts/hbm_70b_optimized_20261015/report.md)。旧 70B 任务没有完整基线结果，因此仍不声称测得 70B 完整流程的加速倍数。

## 复现入口

```powershell
.venv/Scripts/python.exe scripts/benchmark_hbm_numeric.py --mib 128 --repetitions 6
.venv/Scripts/python.exe scripts/benchmark_hbm_serving.py --output artifacts/hbm_execution_performance_20261015/serving-after.json
```

两份脚本支持显式传入本轮诊断保存的旧源码进行对照；旧源码仅为临时测量输入，没有加入仿真器接口或运行时回退路径。具体命令与输出文件见本轮结果。
