LLMCompass · GenZ · ASTRA-sim · SimAI
阵列、缓冲、Roofline 与集合通信；不做器件时序。

「并行」列按 TP / PP / EP 依次给出三个状态。空项为不适用：组件级工具只接受外部给定的工作负载，不评价上层并行策略；纯 DRAM / 网络 / SSD 工具不适用 LLM 服务项。✕ 表示这一层没有入口，不是「做得差」；它的成本可能已被更高层吸收，见下一节。

不支持那一层时，它到底怎么算

这是最容易误读的地方：不展开命令 ≠ 忽略内存。每格上行是成本的真正来源，下行是只改一个参数会发生什么。

工具HBM 成本从哪来只改 tRCDNAND 成本从哪来只改 tPROG

读法：蓝色表示该参数真的进入时间线；红色表示没有对应入口，必须换更高层的有效参数（带宽、时延、profile）或另接模型。把「聚合存储层的带宽」设成 HBF 数值，不会自动产生页编程或擦除。
